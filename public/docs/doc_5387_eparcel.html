ฝ่ายบริการธุรกิจขนส่งและโลจิสติกส์ (บร.) โทร. 0 2831 3555
ที่:
ปณท บร.(บก.1)/5387
วันที่:
17 สิงหาคม 2569
เรื่อง: การให้บริการจัดส่งพัสดุด่วนเพื่อธุรกิจ E-COMMERCE (บริการ E-PARCEL) แก่ผู้ประกอบการ ประจำเดือนสิงหาคม 2569 (เพิ่มเติมครั้งที่ 2)
เรียน: หัวหน้าไปรษณีย์ทุกแห่ง, ผู้จัดการฝ่ายไปรษณีย์นครหลวง/เขต 1-10
ตามที่ บริษัท ไปรษณีย์ไทย จำกัด ได้เปิดให้บริการจัดส่งพัสดุด่วนสำหรับผู้ประกอบการร้านค้าออนไลน์และกลุ่มลูกค้า E-COMMERCE (บริการ E-PARCEL) เพื่อส่งเสริมความสามารถในการแข่งขันทางการค้าของร้านค้าออนไลน์ในประเทศนั้น
เพื่อให้การปฏิบัติงานของเจ้าหน้าที่เคาน์เตอร์รับฝากและระบบจัดส่งพัสดุเป็นไปด้วยความถูกต้อง เรียบร้อย และสะดวกรวดเร็ว จึงขอซักซ้อมและแจ้งแนวทางปฏิบัติดังต่อไปนี้:

1. การรับฝากชิ้นงาน: ให้เจ้าหน้าที่ตรวจสอบหมายเลขสัญญาลูกค้า (Contract ID) หรือบาร์โค้ดที่สร้างผ่านระบบ Prompt Post / API ให้ถูกต้องตรงกับข้อมูลผู้ประกอบการ

2. พิกัดน้ำหนักและขนาด: รองรับพัสดุขนาด ก+ย+ส รวมกันไม่เกิน 150 ซม. และน้ำหนักไม่เกิน 20 กิโลกรัมต่อชิ้น

3. การคัดแยกและส่งต่อ: ให้ดำเนินการปิดถุงส่งต่อศูนย์คัดแยกหลักตามรอบรถตัดตอนปกติ โดยมีระยะเวลานำจ่าย (SLA) 1-2 วันทำการทั่วประเทศ
