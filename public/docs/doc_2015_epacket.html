ส่วนงาน:
ฝ่ายบริการธุรกิจระหว่างประเทศ (บร.) โทร. 0 2831 3811
ที่:
ปณท บร.(จร.1)/2015
วันที่:
17 สิงหาคม 2569
เรื่อง: การดำเนินการต่อสิ่งของบริการ EPACKET ปลายทางสหรัฐอเมริกา และบริการ EPACKET DDP ปลายทางสหภาพยุโรปที่บรรจุผลิตภัณฑ์ประเภทอาหาร และผลิตภัณฑ์ประเภทอาหารเสริม
เรียน: หัวหน้าไปรษณีย์ทุกแห่ง, เจ้าหน้าที่รับฝากระหว่างประเทศ
ด้วยหน่วยงานศุลกากรและหน่วยงานกำกับดูแลด้านอาหารและยาของประเทศปลายทาง ได้แก่ สำนักงานคณะกรรมการอาหารและยาแห่งสหรัฐอเมริกา (U.S. FDA) และสหภาพยุโรป (EU) ได้เข้มงวดในการตรวจสอบการนำเข้าสิ่งของประเภทอาหารและอาหารเสริมที่ส่งผ่านบริการไปรษณีย์ระหว่างประเทศ
ฝ่ายบริการธุรกิจระหว่างประเทศจึงขอแจ้งแนวปฏิบัติสำคัญที่เจ้าหน้าที่รับฝากต้องตรวจสอบ ดังนี้:

1. ปลายทางสหรัฐอเมริกา (USA): ผู้ฝากส่งต้องดำเนินการลงทะเบียนและได้รับหมายเลข FDA Prior Notice Confirmation Number ก่อนการส่ง และพิมพ์เอกสารแนบมาพร้อมกับใบจ่าหน้าพัสดุ

2. ปลายทางสหภาพยุโรป (EU): ต้องใช้บริการ EPACKET DDP (Delivered Duty Paid) พร้อมระบุรหัสพิกัดศุลกากร (HS Code 6 หลัก) และมูลค่าสินค้าเป็นเงินสกุลยูโรให้ชัดเจน

3. ข้อห้ามเด็ดขาด: สิ่งของต้องไม่ใช่ของสด เนื้อสัตว์แปรรูปที่ไม่ผ่านเกณฑ์ หรือผลิตภัณฑ์ที่มีสารควบคุมอันตราย

จึงเรียนมาเพื่อทราบและถือปฏิบัติอย่างเคร่งครัด เพื่อป้องกันการถูกปฏิเสธหรือตีกลับจากศุลกากรปลายทาง
