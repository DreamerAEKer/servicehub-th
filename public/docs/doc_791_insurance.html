ฝ่ายจัดระบบปฏิบัติการไปรษณีย์ (รป.) โทร. 0 2831 3244
ที่:
ปณท รป.(รง.4)/791
วันที่:
17 สิงหาคม 2569
เรื่อง: วิธีปฏิบัติการให้บริการประกันภัยออนไลน์ผ่าน QR CODE ณ ที่ทำการไปรษณีย์ ให้แก่ บริษัท ฟิน อินชัวรันส์ โบรกเกอร์ จำกัด
เรียน: หัวหน้าไปรษณีย์ทุกแห่ง, นายไปรษณีย์ประจำเคาน์เตอร์
ด้วย บริษัท ไปรษณีย์ไทย จำกัด ได้ร่วมมือกับ บริษัท ฟิน อินชัวรันส์ โบรกเกอร์ จำกัด ในการอำนวยความสะดวกให้แก่ประชาชนผู้ใช้บริการ ณ ที่ทำการไปรษณีย์ สามารถเข้าถึงการทำประกันภัยอุบัติเหตุ ประกันการเดินทาง และประกันภัยพัสดุผ่านระบบออนไลน์ได้สะดวกรวดเร็ว
จึงกำหนดวิธีปฏิบัติงานสำหรับเจ้าหน้าที่ประจำเคาน์เตอร์รับฝาก ดังนี้:

1. การติดตั้งสื่อประชาสัมพันธ์: ให้ติดตั้งป้ายตั้งโต๊ะ QR Code ณ บริเวณเคาน์เตอร์รับฝากในตำแหน่งที่ลูกค้ามองเห็นชัดเจน

2. การให้คำแนะนำ: เมื่อลูกค้าสอบถามหรือมีความสนใจ ให้เจ้าหน้าที่แนะนำให้ลูกค้าใช้สมาร์ทโฟนสแกน QR Code เพื่อเลือกดูแบบประกันและกรอกข้อมูลด้วยตนเอง

3. การชำระเงินและรับกรมธรรม์: ลูกค้าสามารถชำระเงินผ่าน Mobile Banking และรับ E-Policy ทาง SMS หรือ E-mail ทันที โดยเจ้าหน้าที่ไม่ต้องออกใบเสร็จรับเงินของ ปณท ซ้ำซ้อน
